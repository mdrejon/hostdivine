Windows Hosting FAQ

Frequently Asked Questions

Helpful answers regarding our Windows hosting and MSSQL databases.

Which versions of ASP.NET and .NET Core are supported?

We support the entire modern and legacy .NET spectrum, including .NET 8.0, 7.0, 6.0, ASP.NET Core, ASP.NET 4.8, 4.7, 3.5, and classic ASP 3.0. You can configure runtime versions individually per domain via Plesk.

Can I connect to my MSSQL database using SQL Server Management Studio (SSMS)?

Yes! Remote database management via SQL Server Management Studio (SSMS) is fully supported on all our Windows plans. You will receive dedicated host credentials and port settings upon signup.

Do you provide dedicated IIS application pools?

Yes, every website on our platform is assigned its own dedicated 64-bit IIS application pool running in Integrated pipeline mode. This guarantees process isolation and robust stability.

Can I import existing .BAK database backups?

Yes, you can easily restore and export native MSSQL .BAK database backup files directly through the Plesk database manager or by opening a ticket with our support team.
