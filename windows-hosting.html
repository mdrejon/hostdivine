Which versions of ASP.NET and .NET are supported?

We support .NET 8.0, 7.0, 6.0, ASP.NET Core, ASP.NET 4.8, 4.7, 3.5 and classic ASP 3.0. You can set the runtime per domain in Plesk.

Can I connect to MSSQL with SSMS?

Yes. Remote management with SQL Server Management Studio is supported on all Windows plans.

Do you provide dedicated IIS application pools?

Yes. Every website gets its own 64-bit IIS application pool in Integrated pipeline mode.

Can I import existing .BAK backups?

Yes. Restore native MSSQL .BAK files through the Plesk database manager or ask our support team.
